[01] ~/loop

The engineering loop

Every task runs the same five stages. No free-form wandering — a packet of work travels the pipe and comes out verified.

  1. 01

    UNDERSTAND

    Bounded tasks, loads only relevant skills

  2. 02

    PLAN

    Architect changes before touching code

  3. 03

    EXECUTE

    Edit with care, multi-file safe

  4. 04

    VERIFY

    Evidence, tests, regression checks

  5. 05

    DELIVER

    Cut releases, accurate docs

[04] ~/install

Get running in minutes

Four commands, one dry-run, zero magic.

// requirements

Git Bash Python 3.10+

Claude installs merge SessionStart config without replacing unrelated settings. Preview with --dry-run first; replacing changed files needs an explicit --force.

Other harnesses and details → README
