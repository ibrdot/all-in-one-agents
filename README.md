An installable agent skill framework — **71 skills, 73 agents, 97 commands** — with an orchestration kernel that turns any harness from an eager intern into a disciplined engineer: UNDERSTAND → PLAN → EXECUTE → VERIFY → DELIVER, with hard gates that block unverified work.

## One-command install

```bash
git clone https://github.com/ibrdot/all-in-one-agents.git
cd all-in-one-agents
./install.sh            # Claude Code  (~/.claude) — wires the SessionStart hook
./install.sh opencode   # OpenCode     (~/.config/opencode)
./install.sh claude --dry-run   # print the settings merge, write nothing
```

The installer wires skills + agents + commands **and** a SessionStart hook so the kernel survives context compaction. Plugin manifests included for 12 harnesses (Claude Code, Cursor, Codex, Gemini, OpenCode, Copilot CLI, Devin, Hermes, Muse, Kimi Code, Pi, Antigravity) — see `docs/INSTALL.md`.

### Quick start (no install)

Can't use hooks or installers? Paste **[MASTER-PROMPT.md](MASTER-PROMPT.md)** into your agent's system prompt / `CLAUDE.md` / `.cursorrules` — the full methodology (5-phase loop, 7 hard rules, 55-entry routing table, anti-patterns, oath) in one portable document.

## What's inside — the core workflow

Seven skills form the backbone; the rest of the pack plugs into it:

1. **brainstorming** — design before code; refuses to build on vague briefs
2. **using-git-worktrees** — isolated branch, green baseline first
3. **writing-plans** — atomic tasks with files, code, verification, rollback
4. **subagent-driven-development** / **executing-plans** — task-by-task execution with review between steps
5. **test-driven-development** — failing test first
6. **requesting-code-review** — independent eyes before merge
7. **finishing-a-development-branch** — suite green, then merge/PR/discard + cleanup

**What actually runs:** `hooks/session-start.sh` emits a Claude Code
`SessionStart` payload containing the full `pack-kernel` and entrypoint text, so the
methodology survives `/clear` and compaction. `hooks/hooks.json` wires it, and
`install.sh` merges that config into `~/.claude/settings.json` idempotently.

`hooks/Stop.md` and `hooks/PostToolUse.md` are written guidance for the agent, not
executable gates. The optional `skills/delivery-gate/hooks/quality-gate.py` can be
wired as a real `Stop` hook if you want mechanical blocking.
